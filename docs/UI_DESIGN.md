# Pulse 音乐播放器 · UI 方案

> 参考对象：[Dopamine](https://github.com/digimezzo/dopamine)（Windows 本地音乐播放器）
> 导航精简为 3 个：艺术家、专辑、文件夹（v0.1.3 去掉了风格、歌曲、播放列表）。
> 目标：保留 Dopamine「大字号文字导航 + 深色 + 单一强调色」的克制感，补上它缺少的几块：正在播放沉浸页、歌词、播放队列抽屉、主题色切换。

截图见 `docs/screenshots/`（由 `preview/` 下的模拟数据渲染）。

---

## 1. 设计原则

| 原则 | 落地方式 |
| --- | --- |
| **文字即导航** | 一级导航直接用 22px 细体中文大字，不用图标侧栏；当前项变白并加 3px 主题色下划线。 |
| **一个强调色** | 全局只有一个 `--accent`（默认 Dopamine 红 `#e53935`），出现在：导航指示条、主按钮、进度条、正在播放的歌曲、复选框勾。其余全部灰阶。 |
| **内容优先** | 去掉系统标题栏（`frame:false`），标题栏、导航、搜索、窗口按钮合为一条 72px 横条。 |
| **左列表 + 右详情** | 艺术家 / 文件夹统一用 30% : 70% 的双栏布局，用户只需学一次。 |
| **键盘与右键可达** | 所有歌曲操作都在右键菜单里；常用操作都有快捷键。 |

## 2. 设计令牌（Design Tokens）

定义在 `src/renderer/styles.css` 的 `:root` 中，改主题只需改这里。

**颜色**

| Token | 值 | 用途 |
| --- | --- | --- |
| `--bg-deep` | `#141414` | 标题栏、播放栏（最深，框住内容） |
| `--bg` | `#1c1c1c` | 左栏背景 |
| `--bg-pane` | `#202020` | 右栏 / 内容区（略亮，形成层次） |
| `--bg-raise` | `#262626` | 输入框、次级按钮、标签 chip |
| `--hover` / `--active` | 白 5% / 9% | 悬停 / 选中叠加 |
| `--text` / `--text-2` / `--text-3` | `#ededed` / `#9b9b9b` / `#626262` | 主文字 / 次文字 / 辅助信息 |
| `--accent` | `#e53935`（可切换 8 色） | 唯一强调色 |

**字体**：`Segoe UI Variable → Segoe UI → 微软雅黑 UI → PingFang SC`

| 层级 | 字号 / 字重 | 场景 |
| --- | --- | --- |
| Nav | 22 / 300（选中 400） | 一级导航、设置分区 |
| H1 | 34 / 600 | 专辑详情标题 |
| H2 | 28 / 400 | 设置页标题 |
| Body-L | 15 | 歌曲标题 |
| Body | 14 | 通用 |
| Caption | 12–13 | 歌手、计数、时长 |

**尺寸**：标题栏 72px · 播放栏 92px · 列表行高 60px · 圆角 6px · 基础间距 4 的倍数（8 / 12 / 16 / 28）。

**动效**：统一缓动 `cubic-bezier(.2,.8,.2,1)`；抽屉 250ms、正在播放页 350ms、悬停 150ms。

## 3. 整体布局

```

│ (●) 艺术家 专辑 文件夹                       [🔍 搜索…]  ≡  ─ □ ✕ │ 72px
├───────────────────────┬──────────────────────────────────────────────┤
│ 艺术家            17  │ 39 歌曲 [周杰伦]          [随机播放][▶播放全部]│
│ ▌周杰伦            3  │ ── 专辑名 ──────────────                     │
│  G.E.M.邓紫棋      4  │  1  告白气球 / 周杰伦        专辑      3:35  │
│  五月天            1  │ ▮▮ 明明就   / 周杰伦        专辑      4:20  │
│  …                    │  …                                            │
│                       │ 1.2 GB                                  2.7 时│
├━━━━━━━━━━━━━━━━━━━━━━━┷━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━┥ ← 进度条（悬停加粗、出现拖动点）
│ [封面] 歌手          ⟲  ⏮  (▶)  ⏭  ⤮              0:00 / 3:58  ☰ 🔊 ━━│ 92px
```

- **进度条贴在播放栏上沿**（同 Dopamine），平时 3px，悬停 5px 并出现白色拖动点，悬停时 tooltip 显示目标时间。
- 播放栏三段式：左「封面 + 歌手/歌名」（点击进入正在播放页）、中「循环 / 上一首 / 播放 / 下一首 / 随机」、右「时间 / 队列 / 音量」。
- 播放键是唯一的实心主题色圆形按钮，视觉重心落在中间。

## 4. 页面规格

### 4.1 艺术家
- 左栏：名称 + 歌曲数，按拼音/字母排序；选中项有左侧 3px 主题色竖条。
- 右栏：按**专辑分组**（专辑标题行 + 年份），组内按碟号、音轨号排序。
- 多艺术家合作曲（如「韩红 / 林俊杰」）会同时出现在每位艺术家下面。

### 4.2 专辑
- 网格：`auto-fill, minmax(168px, 1fr)`，封面懒加载（IntersectionObserver，预加载 300px）。
- 悬停卡片：右下角浮出圆形播放按钮（上移 6px + 淡入）。
- 点击进入专辑详情：200px 大封面 + 「专辑」小标签 + 34px 标题 + 元信息 + 播放/随机按钮。

### 4.3 文件夹
- 左栏顶部下拉切换根文件夹（对应 Dopamine 截图右上角的文件夹下拉），下方是子文件夹（带歌曲数）和「上一级」。
- 右栏显示当前目录直接包含的歌曲，按文件名排序；标签 chip 显示相对路径。

### 4.4 正在播放（沉浸页）
- 点击播放栏左侧封面，从底部滑入覆盖内容区（标题栏和播放栏保留，随时可控制）。
- 背景：当前封面放大 + `blur(70px) saturate(1.4) brightness(.42)`，颜色随歌曲变化。
- 左：大封面（最大 400px，带投影）；右：歌名 / 歌手 · 专辑 / 滚动歌词。
- 歌词：读取同名 `.lrc`（自动识别 UTF-8 / UTF-16 / GBK），也支持内嵌歌词；当前行放大 1.08× 并变白，自动居中；**点击任意一行跳转到该时间**。

### 4.5 播放队列（右侧抽屉）
- 380px 宽，从右侧滑入，带左侧投影；当前曲目高亮。
- 点击跳转，悬停出现 × 移除。随机模式下显示的是打乱后的实际播放顺序。

### 4.6 设置
- 进入设置后，一级导航**原位替换**为「← 音乐库 外观 播放 黑名单」（Dopamine 的做法），返回按钮是主题色圆形。
- **音乐库**：添加文件夹 / 勾选显示 / 移除（悬停出现）/ 每个文件夹的歌曲数 / 立即刷新 / 启动时自动刷新。
- **外观**：8 个主题色圆点，即时生效。
- **播放**：启动时恢复上次队列与进度；快捷键说明。
- **黑名单**：标题用主题色；「清空黑名单…」（二次确认）；逐条移除。

## 5. 组件状态

| 组件 | 默认 | 悬停 | 选中 / 激活 | 特殊 |
| --- | --- | --- | --- | --- |
| 歌曲行 | 透明 | 白 5% | 白 9% | 正在播放：标题变主题色 + 跳动的均衡器图标；黑名单：38% 透明度 + 删除线 |
| 左栏项 | 次文字色 | 白 5% + 主文字色 | 白 9% + 左侧主题色竖条 | — |
| 主按钮 | 主题色实心 | 亮度 +10% | — | — |
| 次按钮 | `--bg-raise` | `#303030` | — | — |
| 图标按钮 | 次文字色 | 圆形白 5% | 主题色（循环 / 随机 / 队列开启时） | 单曲循环图标带「1」 |

## 6. 交互清单

| 操作 | 方式 |
| --- | --- |
| 播放 | 双击歌曲；或右键 → 播放（以当前列表为播放队列） |
| 下一首播放 / 加入队列 | 右键菜单 |
| 黑名单 | 右键 → 加入/移出黑名单；播放时自动跳过 |
| 在资源管理器中显示 | 右键 → 在文件夹中显示 |
| 搜索 | 标题栏搜索框，200ms 防抖，匹配歌名 / 歌手 / 专辑 |
| 快捷键 | `Space` 播放暂停 · `Ctrl+←/→` 上/下一首 · `Ctrl+↑/↓` 音量 · `Ctrl+F` 搜索 · `Esc` 关闭弹层 |
| 系统媒体键 | 通过 MediaSession 接入（键盘媒体键、Windows 媒体浮层显示封面） |

## 7. 空状态与反馈

- 音乐库为空：居中大图标 + 「音乐库是空的」 + 主按钮「添加文件夹」。
- 扫描中：标题栏搜索框左侧出现闪烁的红点 + 「正在扫描 120/560」。
- 所有操作结果用底部居中的 Toast（2.2 秒）提示，不打断操作。
- 删除类操作（移除文件夹、清空黑名单）统一用自绘确认框（Enter 确认 / Esc 取消）。

## 8. 后续迭代建议（v0.2+）

1. **多选**：Ctrl/Shift 多选歌曲，批量加入队列或黑名单。
2. **拖拽**：播放队列内拖拽排序；从资源管理器拖入文件夹。
3. **均衡器**：Web Audio `BiquadFilterNode` × 10 段 + 预设。
4. **迷你播放器**：小窗置顶模式（Dopamine 有 Cover / Microplayer 两种）。
5. **浅色主题**：令牌已经集中，新增一套 `[data-theme=light]` 变量即可。
6. **封面缩略图磁盘缓存**：目前缓存在内存里，曲库很大时可落到 `userData/covers/`。
7. **在线**：Last.fm scrobble、在线歌词/封面补全（对应 Dopamine 的「在线」设置页）。
8. **托盘 + 任务栏缩略图按钮**（上一首/播放/下一首）。
